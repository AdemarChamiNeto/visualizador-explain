Privacidade

O Visualizador de EXPLAIN é um projeto de portfólio. Não tem cadastro nem login.

O que acontece com o que você digita

  • Plano colado: é lido só no seu navegador. Nada vai para o servidor.
  • Consulta no banco de exemplo: vai para o servidor, roda no banco de exemplo (uma loja fictícia) e não é guardada. O servidor só registra erros internos, para corrigir bugs.
  • Limite de uso: o endereço IP é usado por alguns minutos, só em memória, para limitar o número de consultas.

O banco de exemplo tem só dados fictícios, gerados automaticamente. O app roda no Render e o banco no Neon, sempre por HTTPS.
